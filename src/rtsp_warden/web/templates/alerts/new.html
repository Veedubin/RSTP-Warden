Add Notifier

Create a new alert notifier destination.

Note

To add notifiers, edit your config.yaml under the alerts key and restart the server. Example:

alerts:
  enabled: true
  notifiers:
    - name: "My Phone"
      type: ntfy
      url: "https://ntfy.sh"
      topic: "my-warden-alerts"
      enabled: true
      severities: ["warn", "error"]
    - name: "Slack"
      type: webhook
      url: "https://hooks.slack.com/services/..."
      method: POST
      headers:
        Content-Type: "application/json"
      enabled: true
      severities: ["error"]
    - name: "Gmail alerts"
      type: apprise
      urls:
        - "mailto://user:pass@smtp.gmail.com:587"
      title_template: "[{severity}] {camera_name}: {event_type}"
      min_severity: warn
      min_interval_seconds: 60
      enabled: true
