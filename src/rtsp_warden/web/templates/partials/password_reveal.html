{# One-time secret (password or API token) with show/hide and copy. Usage: {% set secret_value = ... %} {% set secret_label = "Password" %} (optional, defaults to "Password") {% include "partials/password_reveal.html" %} The secret is written only into the input's value attribute, where Jinja escapes it. It never appears inside an Alpine/JS expression, so quotes in an admin-typed password can neither break the widget nor inject script. The input starts as type="text" so the secret is readable without JavaScript; Alpine masks it on load. Copy falls back to selecting the text when the Clipboard API is missing (plain-HTTP LAN access is not a secure context). #}
